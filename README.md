# IMDb-Top-1000-Movies-Analysis-Web-Scraping-EDA-Visualization-Project

## Project Overview
This project analyzes IMDb's Top 1000 highest-rated movies through web scraping, data cleaning, exploratory data analysis (EDA), and visualization.

The objective is to uncover patterns and trends among highly rated films and demonstrate end-to-end data analytics skills.

---
## Objectives
* Scrape movie information from IMDb
* Clean and transform raw data
* Perform exploratory data analysis
* Generate actionable insights
* Create compelling visualizations
* Showcase data analytics skills for recruiters and employers

---
## Tools & Technologies
* Python
* BeautifulSoup
* Requests
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Dataset
The dataset was collected directly from IMDb's Top Rated Movies listings through web scraping.

Key features include:

* Title
* Release Year
* Runtime
* Genre
* IMDb Rating
* Director

## Key Analyses
* IMDb Rating Distribution
* Top Rated Movies
* Genre Analysis
* Ratings by Genre
* Movies by Decade
* Ratings by Decade
* Runtime Analysis
* Runtime vs Rating
* Director Analysis
* Actor Frequency Analysis

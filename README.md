# IMDb-Top-1000-Movies-Analysis-Web-Scraping-EDA-Visualization-Project

## Project Overview
This project analyzes IMDb's Top 1000 highest-rated movies through web scraping, data cleaning, exploratory data analysis (EDA), and visualization.

The objective is to uncover patterns and trends among highly rated films and demonstrate end-to-end data analytics skills.

---
## Objectives
* Scrape movie information from IMDb
* Clean and transform raw data
* Perform exploratory data analysis
* Generate actionable insights
* Create compelling visualizations
* Showcase data analytics skills for recruiters and employers

---
## Tools & Technologies
* Python
* BeautifulSoup
* Requests
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

---

## Dataset
The dataset was collected directly from IMDb's Top Rated Movies listings through web scraping.

Key features include:

* Title
* Release Year
* Runtime
* Genre
* IMDb Rating
* Meta Score
* Director
* Votes
* Gross Revenue

## Key Analyses
* IMDb Rating Distribution
* Top Rated Movies
* Genre Analysis
* Ratings by Genre
* Movies by Decade
* Ratings by Decade
* Runtime Analysis
* Runtime vs Rating
* Votes vs Rating
* Director Analysis
* Highest Rated Directors
* Certificate Analysis
* Gross Revenue Analysis
* Correlation Analysis
* Actor Frequency Analysis

## Key Insights
* Drama is the dominant genre among top-rated movies.
* Most movies have ratings between 8.0 and 8.5.
* Certain directors consistently appear in IMDb's Top 1000.
* Higher vote counts generally correspond with stronger ratings.
* Movie production trends vary significantly across decades.

# IMDb-Top-1000-Movies-Analysis-Web-Scraping-EDA-Visualization-Project

## Project Overview
This project analyzes IMDb's Top 1000 highest-rated movies through web scraping, data cleaning, exploratory data analysis (EDA), and visualization.

The objective is to uncover patterns and trends among highly rated films and demonstrate end-to-end data analytics skills.

---
## Objectives
* Scrape movie information from IMDb
* Clean and transform raw data
* Perform exploratory data analysis
* Generate actionable insights
* Create compelling visualizations
* Showcase data analytics skills for recruiters and employers

## Dataset
The dataset was collected directly from IMDb's Top Rated Movies listings through web scraping.

Key features include:

* Title

* Genre
* IMDb Rating
* Director

## Key Findings

1. The dataset contains 1,000 movies released between 1920 and 2018.

2. The average IMDb rating is 7.97.

3. Most movies have ratings between 7.5 and 8.25, indicating a concentration of highly-rated films.

4. The highest-rated movie in the dataset (Shawshank Redemption) achieved a rating of 9.3.

5. The average movie duration is 124 minutes.

6. Drama is the most common genre.

7. Movie production peaked in the 2000's with 217 movies represented in the dataset.

8. The 2020s emerged as the highest-rated decade, recording an average movie rating of 8.19, which surpassed the mean ratings observed in all preceding decades.

9. The majority of movies have runtimes between 90 and 140 minutes.

10. The analysis found a weak positive correlation between movie duration and IMDb rating (r = 0.27). While longer movies tend to achieve marginally higher ratings, the weak strength of the relationship suggests that factors other than duration play a more significant role in determining a movie's rating.

11. The director frequency analysis showed that Steve Spielberg and Alfred Hitchcock had the highest representation in the dataset, each accounting for 13 movies.
